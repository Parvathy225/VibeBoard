# 🎵 VibeBoard

> **Your Mood. One Perfect Atmosphere.**

VibeBoard is a web application that transforms a single mood into a complete immersive experience by combining aesthetic visuals from **Unsplash** and matching ambient content from **YouTube**.

Instead of searching separately for images and videos, users can instantly generate a personalized **Vibe Pack** with one click.

---

## ✨ Features

- 🎨 Preset mood selection (Rainy Café, Midnight Coding, Cozy Autumn, etc.)
- 🔍 Custom mood search
- 📷 High-quality aesthetic images using the Unsplash API
- ▶️ Embedded YouTube ambient playlists/videos
- 🎨 Dynamic UI based on the selected mood
- 💾 Save favorite Vibe Packs using Local Storage
- 📱 Responsive design for desktop and mobile

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Unsplash API
- YouTube Data API v3
- Local Storage

---

## 🔗 API Integration

### 📷 Unsplash API
Fetches aesthetic, high-quality images based on the selected mood.

### ▶️ YouTube Data API v3
Searches and embeds matching ambient music, study playlists, or relaxing videos related to the same mood.

---

## 🚀 How It Works

1. Select one of the preset moods or enter a custom mood.
2. VibeBoard sends the mood as a query to both APIs.
3. Unsplash returns a curated image moodboard.
4. YouTube returns a matching ambience or playlist.
5. Both are combined into a personalized **Vibe Pack**.
